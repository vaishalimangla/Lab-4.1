## 1. How did you approach creating more flexible functions with parameters?
I have created flexible functions by not using hard coded values for the variables.
I used prompts to get the value from the user then called the relevant function for those input values.

Conditional logics were a bit complex, I had to look for the exact syntax used to apply coditional operators.
As the input is prompted , so had to check the values are as per requirement or not. which leads to even more complex conditions. It took multiple iterations to finally get the expected output with all conditions fulfilled.

## 3. How does refactoring improve the readability and maintainability of your code?
Refactoring is definitly improve the readability and maintainabilty as main logic of the existing code didnt change . I have just added the functionality to the existing code. whithout actualy changing the whole code.
I have just added the prompt for the discount variable and added the condition to check discount. Incase discount is available updated the calculation otherwise it doing the existing calculation only.
